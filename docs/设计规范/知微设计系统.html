色彩系统

Foundations / 05

动效

动效服务于反馈，不表演。颜色类过渡用 Tailwind 默认 150ms、cubic-bezier(.4,0,.2,1)；输入框焦点 200ms ease-out；对话框、下拉、气泡、工具提示 100ms 淡入并从 95% 放大；抽屉 200ms 滑入；分段标签指示块 300ms ease-out。所有动效尊重 prefers-reduced-motion。

Guidelines / 交互原则

交互原则

状态可见

每个操作都有反馈：提交中按钮禁用、结果用 Toast、表单内联校验；加载慢时先出骨架屏。删除等破坏性操作走确认框。

键盘可达

基于 Radix 的组件自带焦点管理：可交互元素都有可见焦点环（品牌蓝柔光），Tab 顺序符合视觉顺序，对话框与抽屉可 Esc 关闭。

语义色克制

绿 / 琥珀 / 红只表状态，不作装饰；品牌蓝只用于主操作、选中与焦点，一屏一个重点。

明暗一致

颜色全部走 globals.css 令牌，默认跟随系统，也可手动切换；暗色下链接、焦点和选中文字转亮蓝，主按钮保持品牌蓝白字。

Guidelines / 规约

Do / Don't

Do

一屏一个主按钮承载主操作，其余降级为描边或幽灵按钮。

Don't

并排放多个蓝色主按钮，让管理员无从判断主次。

Do

用语义色表达状态：已连接、自动回复用绿，待人工、人工接待用琥珀，异常与错误用红。

Don't

把品牌蓝当状态色，或用红色做普通强调。

Do

横幅说清现状和去哪里改，并给出链接，例如「到 系统设置 → 群运营 开启」。

Don't

只写「出错了」「操作失败」，不给下一步。

Do

数字与时间列用等宽数字右对齐，群 ID、日志字段用 Mono。

Don't

用正文字体排数字表格，导致列错位、难以扫读。
