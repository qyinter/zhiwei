设计书（docs/设计书/FA-DD-XXX_功能名.html，纯语义 HTML，见 v1.2）统一按以下七章编写，无内容的章节写「无」，不删章：

1. 概要            1.1 目的  1.2 范围  1.3 相关文档  1.4 用语定义
2. 前提            2.1 系统构成  2.2 技术要素  2.3 前提条件・制约事项
3. 功能一览        （功能 ID + 一句话说明 + 对应 API 的总表）
4. 功能详细        （每个功能一节：接口定义、入出力项目表、
                     处理流程 S-01… + mermaid 序列图、异常系 E-01…）
5. 数据定义        5.1 DB 表定义  5.2 设置分区（system_settings key）
6. 错误一览        （全功能错误码汇总表）
7. 配置项          （env / 系统设置中与本功能相关的配置）
  • 处理步骤编号 S-01…、异常编号 E-01…、功能编号 F-01…，便于评审/测试用例引用。
  • 错误 message、TTL 等一律照抄实现，实现变更时文档同步改版（改订履历追加一行）。
